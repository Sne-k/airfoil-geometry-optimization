# Airfoil coordinates

| File | Airfoil | Source |
|---|---|---|
| `clarky.dat` | Clark Y (11.7 % thick, flat lower surface) | [airfoiltools.com](http://airfoiltools.com/airfoil/details?airfoil=clarky-il), based on the UIUC Airfoil Coordinates Database |

Any Selig or Lednicer `.dat` file can be passed to `optimize_airfoil`, e.g.
`optimize_airfoil('airfoils/clarky.dat')` from the `MATLAB` folder.
